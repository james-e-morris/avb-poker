How the Story Point Calculator Works
A. Score Raw Score = Size of Effort x Complexity Multiplier x Uncertainty Multiplier x Cognitive Multiplier x Dependency Multiplier x Risk Multiplier, then rounded to a whole number  (rounded range 1-13)
B. Basis Size options are 1, 2, 3, 5, 8. Every multiplier field uses Low/Medium/High where Low→x1.0, Medium→x1.05, High→x1.1. Top-end example: 8 x 1.1 x 1.1 x 1.1 x 1.1 x 1.1 = 12.88, rounded to 13.
C. SP Suggested SP is the nearest Fibonacci card to the rounded score: 1, 2, 3, 5, 8, 13.
D. Size (BE + FE examples) 1: tiny/localized (BE: rename response field + tests, FE: copy or spacing tweak). 2: small/simple (BE: add optional response field, FE: add minor form option). 3: standard/modest (BE: refactor one handler with helper/query update, FE: new small component using existing contract). 5: multi-step single domain (BE: workflow/refactor with retries/batching, FE: new moderately complex wizard step with validation). 8: large/cross-cutting (BE: cross-system workflow/config integration, FE: major multi-step feature area with multiple screens and edge-case handling).
E. Multiplier range examples Complexity (Low/Med/High): BE add one mapper branch / refactor one handler / coordinate multi-branch orchestration. FE copy/style tune / new component with conditional states / multi-state workflow with validation, retries, and fallbacks. Uncertainty (Low/Med/High): BE clear acceptance on existing API / some contract unknowns / upstream behavior still undefined. FE clear mock + acceptance / partial UX unknowns / behavior still exploratory. Cognitive Load (Low/Med/High): BE one-module edit / a few modules and decisions / many cross-module flows held in sync. FE isolated screen tweak / moderate state coordination / dense cross-screen state and edge-case coordination. Dependencies (Low/Med/High): BE internal-only change / one or two service touchpoints / multiple services or teams synchronized. FE local UI only / one API contract update / cross-team rollout with backend + design coordination. Risk / Impact of Failure (Low/Med/High): BE low-impact non-critical path / moderate user-facing risk / production-critical failure risk. FE cosmetic or low-risk UI / noticeable workflow disruption / high-impact journey breakage with rollback complexity.
