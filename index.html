How the Story Point Calculator Works
A. Score Raw Score = Size of Effort x Complexity Multiplier x Uncertainty Multiplier x Cognitive Multiplier x Dependency Multiplier x Risk Multiplier, then rounded to a whole number  (rounded range 1-12)
B. Basis Size is the base. For every other factor: score 1→x1, 2→x1.05, 3→x1.1, 4→x1.15, 5→x1.2. Example: 5 x 1.05 x 1.05 x 1.05 x 1.05 x 1.05 = 6.38, rounded to 6.
C. SP Suggested SP is the nearest Fibonacci card to the rounded score: 1, 2, 3, 5, 8, 13.
